# Triple Six FTC 26587 Website

Modern Astro starter site.

## Run locally

1. Install Node.js 20+
2. Open a terminal in this folder
3. Run `npm install`
4. Run `npm run dev`

## Build

Run `npm run build`.

## Deploy

Recommended: GitHub + Vercel or Netlify.
